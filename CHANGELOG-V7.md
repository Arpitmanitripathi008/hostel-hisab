# Hostel Hisab V7

## Changes
- Milk records now show a clear green **✓ Saved** state after recording on the Dashboard.
- Dashboard shows saved milk as a status card; detailed milk edits stay in the Milk tab.
- Milk tab can update or remove the selected day's quantity.
- Tiffin advance is now stored separately for each month. Saving an advance for a month replaces that month's previous value instead of adding another payment.
- Existing V5/V6 tiffin payments are migrated into month-specific advances using their payment dates.
- Added a clear email-verification notice during account creation and a confirmation message after Supabase sends the verification email.
- Kept V6 forgot-password, reset-password, and change-password functionality.
- Improved mobile-first layout, spacing, buttons, date controls, forms, and settings rows.
- Updated footer/version to V7.
